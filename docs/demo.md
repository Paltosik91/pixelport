# Демонстрация PixelPort — 3 минуты

**Перед показом:** сервер запущен на чистой демо-базе (`dotnet ef database update` → `dotnet run`),
браузер открыт на http://localhost:5080, игрок — Nova, корзина пуста. Вторая вкладка — `admin.html`.
Код открыт в VS Code на `server/AdminEndpoints.cs`.
