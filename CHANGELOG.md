# Изменения

Формат: новые версии сверху. Номер версии — [семантический](https://semver.org/lang/ru/):
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`.

## 1.0.0 — релиз

### Добавлено
- «Выбор редакции»: бейдж на обложке, фильтр на витрине в обоих режимах, флажок в админке,
  `PUT /api/games/{id}/editors-choice`, параметр `editorsChoice` в `/api/games`.
- Пометка «🆕 новинка» и оценка словами («очень положительные») на карточках игр.
- Понятное сообщение при запуске, если в базе не применены миграции.

### Изменено
- README: запуск из чистого клона, частые проблемы, устройство проекта, обзор API.

## 0.3.0 — магазин с сервером

### Добавлено
- Сервер на ASP.NET Core Minimal API, каталог в PostgreSQL через EF Core и миграции.
- Отзывы игроков, рейтинг, переключатель «Играю как…».
- Админка: новая игра, правка, скидки, удаление.
- Заказы в одной транзакции, цена на момент покупки, библиотека игрока.
- «Вам может понравиться» — похожие игры по общим тегам.
- Статистика продаж: выручка, жанры, топ-5 игр, SVG-диаграмма.

## 0.2.0 — живой магазин

### Добавлено
- Каталог из `data/catalog.json`: загрузка со «скелетами», ошибка и «Повторить».
- Поиск, фильтры, сортировка; страница игры по `game.html?id=…` со слайдером.
- Корзина и «Желаемое» в `localStorage`, промокоды, таймер распродажи, «Игра дня».

## 0.1.0 — витрина

### Добавлено
- Пять страниц на HTML и CSS, тёмная тема на CSS-переменных, сетка каталога на Grid,
  адаптивная вёрстка.
